How to use this
  1. Type a username and press Search.
  2. With the engine running (green dot above), every site is checked in-app — confirmed accounts turn green, and a photo + name appear in the dossier at the top.
  3. Without the engine (this hosted preview), it falls back to quick mode: a few sites are checked live and the rest are direct links.
Run the full engine locally with Docker: docker compose up, then open http://localhost:8000. See the repo README.
