trace-board

A visual OSINT board for investigating a username / handle across platforms. Type a handle and it builds direct profile links grouped by category, so an analyst can pivot quickly. Optionally import a Sherlock results file to light up the accounts that were actually confirmed.
⚖️ Authorised use only. Use this for investigations you have a legitimate reason to run (your own accounts, threat intel, incident response). Respect privacy and local law. Building profile links is not the same as confirming an account exists — that is what the Sherlock import is for.
Using real Sherlock results: run sherlock <username> (see sherlock-project/sherlock), then drag the generated <username>.txt onto "Import Sherlock results" to mark confirmed accounts in green. Curated platform set; not exhaustive. Inspired by Sherlock (MIT). No data leaves your browser.
